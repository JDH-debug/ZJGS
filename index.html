连不上怎么办（最常见原因，按顺序排查）
1. 先用地址栏直测（最能定性）：把下面这行粘到浏览器地址栏回车，地址里的 URL 和 key 会自动带上当前填写的值。
　· 返回 [] 或数据 → 一切正常，直接点「⤒ 全量覆盖上传」
　· 返回 permission denied → 缺授权，SQL Editor 执行 诊断.sql 第 4 段
　· 返回 does not exist → 建表没成功，重跑 supabase_建表.sql
　· 网页打不开 → 本机网络或公司防火墙拦了 supabase.co
2. 还没建表：SQL Editor 执行 supabase_建表.sql（本脚本已禁用 RLS 并补授权）。
3. 缺权限：新版 Supabase 不再自动授权，执行 诊断.sql 第 4 段补 grant。
4. 项目暂停：项目列表看是否为 Active（免费项目长时间不用会自动暂停）。
5. URL 填错：应为 https://xxx.supabase.co，不要拼错项目名。
建表：下载包里的 supabase_建表.sql，在 Supabase 后台 SQL Editor 执行一次。
取 URL 和 key：Supabase 后台 → Project Settings → API → Project URL / Project API keys → anon public。
安全：anon key 会出现在网页源码里，拿到的人可读写数据。仅建议内网/小团队使用；公网请改 Supabase Auth 登录授权。
